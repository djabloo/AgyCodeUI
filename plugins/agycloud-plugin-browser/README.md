# Browser

Fai navigare agy sul web: apri pagine, leggi e riassumi contenuti, controlla
siti, estrai dati e prova moduli. Usa il sotto-agente browser di Google
Antigravity, che pilota il Chromium del tuo ambiente.

## Cosa fa

- **Indirizzo + cosa fare**: scrivi la pagina (facoltativa) e la richiesta,
  poi **Avvia nella Chat**. La richiesta parte nella Chat, dove segui passo
  passo cosa fa l'agente.
- **Esempi pronti**: riassumere una pagina, controllare un sito, estrarre dati
  in tabella, provare un modulo senza inviarlo, confrontare pagine, cercare sul
  web.
- **Stato di Chromium**: la scheda ti dice se il browser è disponibile
  nell'ambiente.

`Ctrl+Invio` nel campo della richiesta avvia subito.

Il comando `/browser` resta sempre disponibile anche direttamente in Chat.

## Come si usa

1. **Impostazioni → Plugin → Browser → Installa**: compare la scheda in alto.
2. Con l'interruttore puoi **spegnerlo** quando non ti serve: la scheda sparisce
   dal menu.

## Privacy

Le pagine vengono aperte dal Chromium del tuo ambiente e il contenuto passa ad
agy con il tuo account Google, come qualsiasi altra richiesta in Chat. Per
pagine con dati riservati valuta prima cosa chiedi all'agente.

## Disponibilità

Self-hosted (serve Chrome o Chromium sul server) e AgyCloud dal piano Hobby
in su, dove Chromium è già incluso.
