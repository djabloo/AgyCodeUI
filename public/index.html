🛡️ Permessi & Sicurezza Antigravity

Configura i permessi di esecuzione per la CLI Antigravity, la whitelist dei comandi approvati e la sicurezza di rete.

Modalità Esecuzione e Permessi CLI

Auto-approva tutti i permessi degli strumenti (--dangerously-skip-permissions) Consente all'agente di eseguire comandi bash, creare ed editare file senza chiedere conferma interattiva (y/n).
Modalità Sandbox (--sandbox) Esegue l'agente all'interno di un ambiente isolato con restrizioni sui comandi di sistema.
Consenti Accesso Fuori Workspace (allowNonWorkspaceAccess) Permette ad Antigravity di leggere e referenziare file di configurazione situati all'esterno del workspace corrente.

⚡ Comandi Shell Autorizzati (Whitelist)

Comandi bash che Antigravity può eseguire direttamente senza richiedere autorizzazione manuale ad ogni turn.

PIN di Protezione Web UI

Protegge l'interfaccia da accessi non autorizzati da smartphone o browser remoto.

Cartella di Lavoro Iniziale (WORKSPACE_DIR)

Directory root in cui Antigravity CLI e il file explorer operano.
